================================================================================
                        1. PLATFORM OVERVIEW
================================================================================

NEXORA is a skill-based social platform that combines professional networking
with gamification elements. Users develop skills, compete in PvP battles,
join communities, and connect with others who have complementary or related skills.

VISION: LinkedIn + Discord + Gaming + Gen-Z Future Network

KEY CONCEPTS:
- SKILLS: Users possess skills with levels (Beginner, Intermediate, Advanced, Expert, Master)
- XP (Experience Points): Earned through activities, battles, and accomplishments
- RANK: Progression system (Novice, Bronze, Silver, Gold, Platinum, Diamond, Master, Grandmaster)
- PvP BATTLES: Real-time skill-based competitions between users
- COMMUNITIES: Skill-based groups where users collaborate and learn
- AI COACH: Personalized learning guidance and recommendations

================================================================================
                        2. USER ROLES & EXPERIENCE
================================================================================

NEW USER (Unauthenticated):
- Lands on Index page with marketing content
- Can view Hero, Features, PvP Preview, Community Preview, Leaderboard
- Must sign up/login to access platform features

AUTHENTICATED USER (Onboarding Incomplete):
- Redirected to /onboarding to complete profile setup
- Must select skills, interests, and complete profile

AUTHENTICATED USER (Fully Onboarded):
- Full access to all platform features
- Can battle, message, join communities, create content

================================================================================
                        8. AUTHENTICATION & SECURITY
================================================================================

AUTHENTICATION:
- JWT-based authentication
- Token stored in localStorage (access_token)
- Token passed in Authorization header: Bearer {token}
- Session expires based on JWT_SECRET configuration
- Automatic token refresh (if implemented)

LOGIN ENDPOINT:
- POST /auth/login
- Body: { email, password }
- Response: { access_token, token_type, user_id, username, display_name, avatar_url, onboarding_completed }

SIGNUP ENDPOINT:
- POST /auth/signup
- Body: { email, password, username, display_name, avatar_url }
- Response: { access_token, ... }

ONBOARDING:
- /auth/onboarding/skills - Save selected skills
- /auth/onboarding/interests - Save interests
- /auth/onboarding/profile - Save profile details

SECURITY FEATURES:
- Password hashing (bcrypt)
- SQL injection prevention
- CORS configuration
- Rate limiting
- Input validation
