================================================================================
                        1. PLATFORM OVERVIEW
================================================================================

NEXORA is a skill-based social platform that combines professional networking
with gamification elements. Users develop skills, compete in PvP battles,
join communities, and connect with others who have complementary or related skills.

VISION: LinkedIn + Discord + Gaming + Gen-Z Future Network

KEY CONCEPTS:
- SKILLS: Users possess skills with levels (Beginner, Intermediate, Advanced, Expert, Master)
- XP (Experience Points): Earned through activities, battles, and accomplishments
- RANK: Progression system (Novice, Bronze, Silver, Gold, Platinum, Diamond, Master, Grandmaster)
- PvP BATTLES: Real-time skill-based competitions between users
- COMMUNITIES: Skill-based groups where users collaborate and learn
- AI COACH: Personalized learning guidance and recommendations

================================================================================
                        2. USER ROLES & EXPERIENCE
================================================================================

NEW USER (Unauthenticated):

FIXES IMPLEMENTED:

1. SEARCH API REFACTORING (backend/routers/search.py):
   - Refactored `search_users` to use inclusive `LEFT OUTER JOIN` across Users, Skills, and Categories.
   - Users are now ALWAYS visible in general discovery even if they have zero skills listed.
   - Unified `ILIKE` search: Query string now matches against `username`, `display_name`, `bio`, and `skill_name` simultaneously.
   - Added `.distinct()` to ensure user unique records in joined results.
   - Response now consistently includes `avatar_url` and `xp_points` (mapped from backend).

2. FRONTEND DISCOVERY HUB (PeopleDiscovery.tsx):
   - Integrated "Reset Search" functionality in empty states.
   - Updated mapping to use `avatar_url` as primary image source.
   - Improved skill pill rendering to handle both object and string formats.
   - Premium "The Nexus is Quiet" empty state for zero-result scenarios.

3. PERFORMANCE & RELIABILITY:
   - Added loading skeletons that persist until API response.
   - Optimized join logic to maintain sub-100ms response times for 31+ test users.

================================================================================
                        8. AUTHENTICATION & SECURITY
================================================================================

AUTHENTICATION & HYDRATION (NEW):
- Gated Application Rendering: `App.tsx` now uses an `AppContent` component that blocks the router until session hydration is complete.
- Cinematic Loader: A dedicated "Initializing Nexora" loading screen eliminates white-flash refreshes.
- JWT-based authentication with token stored in `localStorage` (access_token).
- Automatic redirection to `/auth` if no valid session is found during hydration.

PROFILE DATA PERSISTENCE:
- Atomic PATCH updates: `PATCH /users/me` uses Pydantic's `exclude_unset=True`.
- Update resilience: Editing a bio or display name does NOT overwrite existing complex JSON fields (Experience, Education, Projects).
- UI Re-sync: `ProfileEditModal` triggers an explicit re-fetch from `/users/me` upon successful updates.

LOGIN ENDPOINT:
- POST /auth/login
- Body: { email, password }
- Response: { access_token, token_type, user_id, username, display_name, avatar_url, onboarding_completed }

SIGNUP ENDPOINT:
- POST /auth/signup
- Body: { email, password, username, display_name, avatar_url }
- Response: { access_token, ... }

SECURITY FEATURES:
- Password hashing (bcrypt)
- SQL injection prevention via SQLAlchemy ORM
- CORS configuration for Docker/Local environments
- Rate limiting on Auth endpoints
- Input validation via Pydantic schemas

  GET /social/following/{user_id}  — same enrichment
  DELETE /social/followers/{id}    — remove a follower from your list

FOLLOW SYSTEM:
  POST /social/follow/{user_id}    — follow user
  POST /social/unfollow/{user_id}  — unfollow user
  GET  /social/is-following/{id}   — check follow status
  GET  /social/recommendations     — AI-powered follow suggestions

REAL-TIME:
  - Follow/unfollow instantly updates UI (optimistic)
  - Redis pub/sub emits follow_created event
  - Reputation service listens and updates target user's score
  - Notification created for new follower

    Body: { target_user_id, skill_name, action: "add"|"remove" }

  GET /skills/endorsements/{user_id}
    - Returns all endorsements received by a user
